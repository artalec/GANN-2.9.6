# GANN Player для macOS

Плеер с плейлистами, обрезкой треков (Start / End), плавными переходами между треками и восстановлением пропавших файлов.

Минимальная версия macOS: 14 (Sonoma). Сборка: Swift 6.0 / Xcode 16.

## Возможности

### Треки и плейлисты
- Добавление треков в выбранный плейлист. Название, длительность, размер и SHA-256 фиксируются при добавлении.
- Выбор нескольких треков, удаление выделенных, перетаскивание для смены порядка.
- Перенос треков между плейлистами.
- У каждого плейлиста свой цвет (10 цветов палитры). У трека может быть свой цвет, он важнее цвета плейлиста.
- Плейлисты можно экспортировать в файл `.djplaylist.json` и импортировать обратно.
- Плейлист можно перетащить в папку Finder: там создастся папка с его названием и копиями всех треков. Копирование происходит в момент броска (file promise), временных копий нет. Одинаковые имена получают суффикс « 2», пропавшие файлы пропускаются.
- Настройки: зацикливание трека, зацикливание плейлиста, автопереход к следующему треку, удаление трека после проигрывания.

### Waveform и обрезка
- Волна трека с отметкой текущей позиции.
- Маркеры Start и End перетягиваются мышью. Во время перетягивания воспроизведение не прерывается и не сдвигается: новые границы применяются при отпускании кнопки.
- Клик по волне во время игры переводит трек к выбранной точке с плавным переходом 0,5 с. Перетаскивание по волне перематывает без перехода.
- Цвет волны закреплён за треком: берётся цвет трека, а если он не задан, цвет плейлиста, в котором трек лежит.

### Переходы
- **Crossfade** — плавный переход между треками.
- **High-cut** — фильтр высоких частот при переходе, с настраиваемой паузой после.
- **Focus Fade** — плавная остановка при уходе в другую программу и плавное возобновление.

### Вывод звука
- Справа от громкости выбирается устройство вывода (встроенные динамики, наушники, USB, Bluetooth). Список обновляется сам при подключении и отключении. Выбор сохраняется.
- Переключение устройства во время игры продолжает трек с той же точки: звук короткое время прерывается.

### Focus Fade
- При уходе из плеера трек плавно затихает и ставится на паузу. При возврате громкость плавно поднимается с нуля, без щелчка.

### Нижняя строка
Показывает параметры выделенного трека (а если ничего не выделено, играющего): битрейт, частоту дискретизации, каналы и размер файла. Если файл пропал, строка показывает «файл не найден».

### Пропавшие файлы
Если трек удалён или перемещён, плеер помечает его значком с восклицательным знаком и ищет файл по всему компьютеру в фоне:

1. Сначала Spotlight (`mdfind`), если индекс включён.
2. Затем Музыка, Загрузки, Документы, Рабочий стол и iCloud Drive.
3. Затем внешние диски и остальные места.

Файл заменяет пропавший только при полном совпадении **имени, размера и SHA-256**. Корзина не просматривается. Трек сохраняет свой идентификатор, поэтому все настройки, обрезка, цвет и журнал изменений переходят на найденный файл. Такой трек помечается значком **©** вместо ноты.

Поиск повторяется через 1, 5, 15 и 30 минут, всего до 6 автоматических попыток; затем автопоиск останавливается, чтобы не держать диск в постоянном обходе. Статус видно в подсказке к значку трека. Искать снова можно вручную из меню **Найти пропавшие треки сейчас**.

Если у трека нет отпечатка (например, он добавлен до версии 26 и файл был недоступен), замена невозможна: перетащите трек заново.

## Управление

| Действие | Как |
|---|---|
| Воспроизведение / пауза | Пробел |
| Стоп | Esc или ⌘. |
| Предыдущий / следующий трек | ⌘← / ⌘→ |
| Удалить выделенные треки | ⌘⌫ |
| Найти пропавшие треки | Меню → Найти пропавшие треки сейчас |
| Выбор плейлиста | Левая колонка; её можно скрыть кнопкой у края окна |

## Где хранятся данные

| Что | Где |
|---|---|
| Плейлисты, треки, настройки | `~/Library/Application Support/GANN Player/appstate.json` |
| Журнал поиска пропавших файлов | `~/Library/Application Support/GANN Player/recovery.log` |

При первом запуске после переименования из старой папки `DJPlayer` копируются `appstate.json` и `recovery.log`. Старая папка не удаляется.

Журнал также пишется в системный журнал. Просмотр:
```bash
log show --last 10m --predicate 'eventMessage CONTAINS "GANN Player"' --info
```

## Сборка

```bash
swift build -c release
swift run -c release
```

Сборка на GitHub Actions описана в `.github/workflows/build.yml`: она собирает `GANNPlayer` и упаковывает его в `GANN Player.app`.

## Структура исходников

| Файл | Назначение |
|---|---|
| `GANNPlayerApp.swift` | Точка входа, меню и горячие клавиши |
| `AppModel.swift` | Состояние приложения: плейлисты, выбор, обрезка, переходы, сохранение |
| `AudioEngine.swift` | Воспроизведение, кроссфейд, high-cut, потоковое чтение файла |
| `ContentView.swift` | Главное окно, панель с волной, эффекты, транспорт |
| `WaveformView.swift` | Волна, маркеры Start / End, перемотка |
| `WaveformGenerator.swift` | Расчёт пиков волны в фоне |
| `TrackList.swift` | Список треков |
| `TrackInfoBar.swift` | Нижняя строка с параметрами трека |
| `PlaylistSidebar.swift` | Список плейлистов |
| `FileFingerprint.swift` | Размер и SHA-256 файла |
| `FileRecovery.swift` | Поиск пропавшего файла по всему компьютеру |
| `RecoveryScheduler.swift` | Планирование повторов поиска и статус |
| `StorageManager.swift` | Сохранение и импорт/экспорт плейлистов |
| `Models.swift` | Модели `Track`, `Playlist`, `AppState`, журнал изменений |

## Известные ограничения

- Переключение устройства вывода прерывает звук на долю секунды: движок перезапускается.
- Копирование плейлиста в Finder выполняется после броска, поэтому для большого плейлиста Finder показывает прогресс, а сам бросок завершается не сразу.
- Замена пропавшего файла возможна только при совпадении отпечатка. Переименованная, перекодированная или отредактированная копия не будет найдена.
- При применении новых границ обрезки воспроизведение перезапускается на той же позиции файла. Если точка оказалась вне нового отрезка, трек начинается с нового Start.
- Поиск по всему компьютеру может занимать заметное время на больших дисках. Чтобы macOS не закрывала доступ к папкам, выдайте приложению полный доступ к диску: Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску.
